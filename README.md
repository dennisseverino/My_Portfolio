# My Portfolio

  A modern personal portfolio website built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion. It showcases my work as a Full Stack Developer, including web, mobile, admin, payment,
  and e-commerce system experience.

  The site includes sections for my profile, experience, skills, projects, resume, and contact information. It also includes a production-ready contact form powered by a Vercel serverless
  function that saves inquiries directly to Google Sheets.

  ## Highlights

  - Full stack developer portfolio
  - Web, mobile, admin, payment, and e-commerce experience
  - AI-assisted engineering workflow with AI CLI, MCP, custom AI skills, testing, and automation
  - Animated responsive UI
  - Downloadable resume
  - Contact form integrated with Google Sheets via Vercel API route
